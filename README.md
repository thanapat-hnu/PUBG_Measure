# PUBG วัดระยะ

โปรแกรมเล็กๆ สำหรับ Windows ที่วัดระยะเส้นตรงบนแผนที่ PUBG ให้อัตโนมัติ
ทำงานด้วยการแคปหน้าจอจากภายนอกเท่านั้น ไม่อ่านหน่วยความจำและไม่แตะไฟล์ของเกม

## ทำอะไรได้
- หาเส้นตรงของผู้เล่น P1 เหลือง, P2 ส้ม/แดง, P3 น้ำเงิน, P4 เขียว (ข้ามเส้นขาวของเครื่องบิน)
- ทาบเส้นกับตารางบนแผนที่ นับช่องเต็มกับเศษช่อง แล้วคิดระยะด้วยพีทาโกรัส
- หาขนาดตารางเองทุกครั้ง ใช้ได้ทุกแมพและทุกระดับซูม (ช่องเล็ก 100 ม. / ช่องใหญ่ 1000 ม.)
- กด 1 ครั้ง = วัด 3 รอบแล้วเฉลี่ย
- แสดงตัวเลขทับบนเกม สีเดียวกับเส้น ถ้าเส้นยาวเลยขอบจอจะขึ้นเป็น "≥"
- แจ้งเตือนเป็นตัวแดงเมื่อข้อมูลไม่ชัด เช่น แยกไม่ได้ว่าเป็นช่อง 100 หรือ 1000
- สั่งด้วยเสียงได้ ("วัดระยะทาง") โปรแกรมเรียนจากเสียงตัวอย่างของผู้ใช้เอง

## ติดตั้งและเปิดใช้
1. ดาวน์โหลดไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. ดับเบิลคลิก `66031036_PUBG วัดระยะ.bat`
   - ถ้าไม่มี Python จะติดตั้งให้ผ่าน winget
   - ถ้าไลบรารีไม่ครบจะติดตั้งให้ (`requirements.txt`)
3. ตั้งเกมเป็น **Borderless Windowed**

## ปุ่ม
| ปุ่ม | หน้าที่ |
|---|---|
| F8 / "วัด" | วัดระยะ (เปิดแผนที่ M ก่อน) |
| F9 / "อัตโนมัติ" | ถ้าเห็นตารางระดับเดียว สลับ อัตโนมัติ / 100 ม. / 1000 ม. |
| คลิกช่องสี | เปิด/ปิดผู้เล่นคนนั้น (เช่น ตอนเล่นคนเดียว) |
| "สี" | ดู/ตั้งสีเส้นแต่ละคน จิ้มสีจากจอได้ |
| "เสียง" | เปิดคำสั่งเสียง |
| "อัด" | อัดเสียงตัวอย่างคำว่า "วัดระยะทาง" (เก็บในโฟลเดอร์ `voice`) |

ค่าที่ตั้งไว้ถูกเก็บใน `pubg_measure_config.json` ปิดเปิดโปรแกรมใหม่ก็ยังอยู่

## ข้อจำกัด
- เส้นต้องเป็นเส้นตรง
- ตารางต้องมองเห็นบนจอ
- เห็นตารางแค่ระดับเดียวที่ขนาดกำกวม จะคิดเป็นช่อง 100 ม. แล้วขึ้นค่าแบบช่อง 1000 ม. ให้ดูด้วย
- คำสั่งเสียงจับตามเสียงของคนที่อัดตัวอย่างไว้
